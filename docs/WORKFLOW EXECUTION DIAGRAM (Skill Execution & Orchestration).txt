┌─────────────────────────────────────────────────────────────────┐
│  2. WORKFLOW INITIALIZATION                                     │
│  • Generate workflow_id                                         │
│  • Set status = PENDING → IN_PROGRESS                           │
│  • Initialize step cursor & execution context                   │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. STEP ORCHESTRATOR (SimpleOrchestrator Loop)                 │
│                                                                  │
│  WHILE steps_remaining:                                          │
│    │                                                             │
│    ├─ GET next_step (type: CHECK / ACTION / VERIFY / NOTIFY)    │
│    │                                                             │
│    ├─ IF type = CHECK:                                          │
│    │   → Validate preconditions & system state                  │
│    │   → Branch logic (if/else)                                 │
│    │                                                             │
│    ├─ IF type = ACTION:                                         │
│    │   → Build ToolRequest / AgentInput                         │
│    │   → Delegate to ToolGateway or AgentService                │
│    │   → Await execution result                                 │
│    │                                                             │
│    ├─ IF type = VERIFY:                                         │
│    │   → Trigger state re-check                                 │
│    │   → Compare expected vs actual                             │
│    │                                                             │
│    ├─ LOG step via RunLedger (status, cost, timestamp)          │
│    │                                                             │
│    ├─ IF step_success → advance cursor                          │
│    │                                                             │
│    └─ IF step_failure → trigger retry_or_escalate               │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
